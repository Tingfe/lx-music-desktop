# 桌面端上游同步与升级说明

## 本次版本

- Fork 版本：2.12.7。
- 审查日期：2026-10-11。
- 上游稳定分支参考：lyswhut/lx-music-desktop v2.12.6，ad95d5091c9ed689fa72b5e5c849df65f5a679ce；另选取 dev 3dda0f4c 的 Wayland 修复。
- 采用选择性移植，不代表完整合入上游全部提交；不覆盖发布流程、Fork 地址和原有定制。

## 引入内容

- QQ 音乐搜索请求与响应结构、歌单导入/翻页和推荐列表修复。
- 酷狗搜索结果、分享歌单完整分页，避免部分歌曲缺失。
- 咪咕封面/歌词修复、酷我歌单数据显示优化。
- 自动换源增加版本关键词校验，减少匹配到伴奏、现场版等错误版本。
- QQ QRC 改为纯 JavaScript 解密，酷我歌词流程及毫秒时间格式修复。
- 修复添加、移动歌曲后保存顺序错误；修复本地文件名含 # 和主题背景路径问题。
- 修复更新检查无条件标为最新版；失败显示未知，旧请求不能覆盖新结果。
- 正式版与测试版按版本选择；测试包无自动更新清单时提供本 Fork 下载页，不假装自动安装。
- 同步连接最多跟随 3 次同源重定向，拒绝跨域、变更端口和协议降级。
- 引入窗口边框/F11、Linux Wayland 显示回退修复；不覆盖 Fork 更新地址。
- 小范围依赖更新和版本固定；Electron/SQLite 主版本升级暂不合入。

## 保留的边界

- 自定义 JS 音源、歌单、收藏和跨端偏好同步保持原有扩展协议；服务端本轮无需更新。
- 主题、语言、布局、设备路径和认证信息不作为跨端通用设置覆盖。
- GD 必须手动选择；不增加自动兜底，不开放下载，不把临时播放地址写进共享持久缓存。
- 保留项目许可证和上游归属说明；新增文档不含账号口令、设备信息或私有服务地址。

## 升级方式

1. 从本 Fork Releases 下载本次测试版对应系统安装包。
2. 先导出歌单备份，再覆盖安装；不要为了更新主动清空数据。
3. 默认检查正式版；启用测试版选项后可发现较新的测试版本，并打开本仓库的对应发布页手动下载安装。
4. 若上游接口仍被平台限流或调整，代码修复不代表所有网络环境都保证可用。

## 验证与待验证

- 自动回归：搜索响应、酷狗完整分页、版本匹配、QRC 固定文本往返、GD 缓存隔离、稀疏数据库顺序、更新状态和安全重定向。
- 本地生产构建；Windows/macOS/Linux 安装包由 GitHub Actions 构建。
- 云端构建成功只代表产物生成，不等于手机/实车/所有桌面系统验收。
- 真机需测试：QQ/酷狗歌单导入、搜索、歌词跟随、切换音源、重连和旧数据保留。
