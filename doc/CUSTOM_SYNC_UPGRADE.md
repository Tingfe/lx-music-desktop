# 自定义同步升级说明

本 Fork 将桌面客户端接入 `Tingfe/lx-music-sync-server` 的扩展同步协议。

## 已同步内容

- 我的列表与不喜欢列表（原有功能）。
- 设置中的自定义音源：同步元信息和完整 JavaScript 脚本；桌面端会自动处理内部压缩存储格式，因此可与手机端直接互通。
- 跨设备体验设置：歌曲来源名显示方式、播放模式与音质、播放速率、歌词翻译/罗马音显示、保存播放进度、搜索热搜/历史、列表点击播放/来源显示/滚动位置/添加位置。

不会同步语言、主题、同步服务器地址、连接码、设备密钥、代理、下载与缓存路径、音频输出设备、音量及桌面窗口/桌面歌词等硬件或设备专属配置。语言 ID 与主题资源都在每台设备本地管理；这样可避免移动端 `zh_cn` 与桌面端 `zh-cn` 等不同格式互相覆盖。旧同步数据写入了不存在的主题或语言时，桌面端会自动回退至内置可用值。

## 升级与验证

1. 将同步服务升级到 `tingfe/lx-music-sync-server:v2.1.10` 或更高版本，并保留原 `/server/data` 目录。
2. 桌面端和手机端均连接同一个同步账号。
3. 在任一端导入或删除自定义音源，另一端在线时应收到更新；首次连接时以服务端已有数据为准。
4. 在任一端修改白名单内的设置，另一端在线时应同步应用。

若服务端迁移、恢复数据目录或调整用户名导致旧密钥失效，桌面端会打开连接码输入框。重新输入连接码即可；无需清除应用数据。

## 设备状态与移除

桌面端连接成功后，在「设置 → 数据同步」可打开「已连接设备」。列表显示同一同步账号下设备的在线状态及最近完成同步时间；可移除其他设备以撤销其访问权限。当前设备不能在这里移除自己，以免误操作导致立即失去管理入口。

该入口需要服务端 `v2.1.8` 或更高版本。连接到旧服务端时，既有同步不受影响，但设备列表不会可用。

## 发布来源

本 Fork 的桌面端自动更新地址为 `Tingfe/lx-music-desktop` 的 GitHub Releases，不会下载原作者仓库的安装包。

- 推送至 `master`：构建多平台测试包，并以 `test-v<运行号>` 创建 GitHub Pre-release；测试版只用于手动下载验证，不会被应用内更新识别。
- 推送 `vX.Y.Z` Git tag：构建并发布正式多平台安装包。应用内自动更新仅从正式 Release 获取更新。
